ELVÉ — SITIO WEB / PROTOTIPO
============================

Abre index.html en un navegador para ver la tienda.

Incluye:
- Home / Hero
- ELVÉ WOMAN y ELVÉ MAN
- Primera colección THE BEGINNING
- Productos de muestra
- Carrito funcional de demostración
- Manifiesto
- Historia de marca
- Newsletter
- Diseño responsive para móvil y desktop

IMPORTANTE
-----------
Los productos, precios, fotografías, métodos de pago, datos de contacto y pedidos son demostrativos.
Antes de publicar, sustituir:
1. Fotografías por las fotos reales de ELVÉ.
2. Precios y productos.
3. Instagram y contacto.
4. Sistema real de pedidos/pagos.
5. Políticas de envío, cambios y privacidad.
